Dictamen Técnico: Requerimientos Docente Reinaldo Rojas

1. Alcance Exclusivo - Iteración 1:

Se implementa exclusivamente el módulo de Entrada y Salida. No se incluyen módulos complejos de gestión de usuarios ni pasarelas de pago (postergados a iteraciones 2 y 3).

2. Modalidad Exclusiva de Mensualidad:

El parqueadero opera 100% por mensualidad. No existen cobros por fracción, hora o día. Tarifas oficiales: $250.000 (Carro) y $100.000 (Moto). El cobro es por vehículo.

3. Capacidad Exacta de 80 Celdas:

Dispone de exactamente 80 celdas fijas: 10 para Motos (M-01 a M-10) y 70 para Carros (C-01 a C-70). El sistema bloquea el ingreso si no hay cupo disponible.

4. Asignación Dinámica / Aleatoria:

La celda se selecciona aleatoriamente por software entre las celdas disponibles para ese tipo de vehículo. No hay celdas fijas por cliente.

5. Validación Estricta de Pago y Seguridad:

Si la mensualidad está vencida, el sistema deniega el ingreso. Se valida y muestra: Placa, Tipo, Marca, Modelo y Color.

6. Operación 24/7:

El sistema cuenta con reloj operativo en tiempo real, registro de timestamps de entrada y salida, y liberación de celda inmediata al egreso.
